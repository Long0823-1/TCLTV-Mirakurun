# CATVトランスモジュレーション（ISDB-C）

対応G06で、CATVの64QAM／256QAM放送を内蔵チューナーから受信します。J:COMなどの同軸はTVの**地デジ端子**へ接続してください。BS/CS端子では比較試験でQAMロックを得られていません。

1. CATV対応版のAPKを更新し、通常の「セットアップ / 局更新」と再起動を行います。
2. 「CATVをスキャン・局更新（配信を一時停止）」を実行します。数分かかります。
3. 完了するとCATVの全番組を種別 `SKY` としてMirakurunへ登録し、自動起動が有効なら配信を再開します。CATVを受信できるのは内蔵チューナー1だけなので、`SKY` はチューナー1（`TCL-G06-1`）にだけ割り当てます。

地デジ・衛星の局設定も保持します。同じ多重がCATVと衛星の両方にある場合はCATVを優先します。チューナー0は `[GR, BS, CS]`、チューナー1は `[GR, BS, CS, SKY]` で、 `ONID_TSID_SID` の選局指定をそのまま使い、配信本体が周波数とTSMF設定を選びます。

共有するネイティブ実装はTCLTV-BondriverのCATV対応版です。スキャン結果はTV内の `/data/local/tmp/tsd_catv_channels` に保存され、BonDriver側とも共用できます。スキャン失敗時には前のCATV局一覧を保持します。

実機ではJ:COMのBS11を地デジ端子経由で受信し、通常のB-CAS処理を使う1920×1080映像と48kHz音声を確認しました。受信可能な番組は信号・契約・カードの条件によります。
