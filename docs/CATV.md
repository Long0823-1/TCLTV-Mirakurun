# CATVトランスモジュレーション（ISDB-C）

対応G06で、CATVの64QAM／256QAM放送を内蔵の2チューナーとも受信できます。J:COMなどの同軸はTVの**地デジ端子**へ接続してください。BS/CS端子では比較試験でQAMロックを得られていません。

1. CATV対応版のAPKを更新し、通常の「セットアップ / 局更新」と再起動を行います。
2. 「3. CATVをスキャン・局更新」を実行します。Mirakurunを自動で停止してからスキャンし、完了後に局一覧とチューナー設定を更新してMirakurunを再開します。約5〜10分かかり、進行状況（％・周波数・見つかった番組数・残り時間）が画面に表示されます。
3. 完了するとCATVの全番組を種別 `SKY` としてMirakurunへ登録し、自動起動が有効なら配信を再開します。`SKY` は2つのチューナー（`TCL-G06-0` / `TCL-G06-1`）どちらにも割り当てます。有料放送の局も一覧には出ますが、契約とB-CASの条件で映像が出ない場合があります。

地デジ・衛星の局設定も保持します。同じ多重がCATVと衛星の両方にある場合はCATVを優先します。両チューナーとも `[GR, BS, CS, SKY]` で、 `ONID_TSID_SID` の選局指定をそのまま使い、配信本体が周波数とTSMF設定を選びます。

共有するネイティブ実装はTCLTV-BondriverのCATV対応版です。スキャン結果はTV内の `/data/local/tmp/tsd_catv_channels` に保存され、BonDriver側とも共用できます。スキャン失敗時には前のCATV局一覧を保持します。

J:COMでは、CATVの専門チャンネルに加えて、CATV経由のBS（BS11・BS朝日・BS-TBS・BS日テレ・BSフジなど）も `SKY` として登録されます。Mirakurunが各多重の局情報を取得し終えるまで、起動後しばらくかかります（取得に失敗した多重は180秒ごとに自動で再試行されます）。
実機ではJ:COMのBS11を地デジ端子経由で受信し、通常のB-CAS処理を使う1920×1080映像と48kHz音声を確認しました。受信可能な番組は信号・契約・カードの条件によります。
