# CATVトランスモジュレーション（ISDB-C）

対応G06で、CATVの64QAM／256QAM放送を内蔵の2チューナーとも受信できます。J:COMなどの同軸はTVの**地デジ端子**へ接続してください。BS/CS端子では比較試験でQAMロックを得られていません。

1. CATV対応版のAPKを更新し、通常の「セットアップ / 局更新」と再起動を行います。
2. 「3. CATVをスキャン・局更新」を実行します。Mirakurunを自動で停止してからスキャンし、完了後に局一覧とチューナー設定を更新してMirakurunを再開します。約5〜10分かかり、進行状況（％・周波数・見つかった番組数・残り時間）が画面に表示されます。
3. 完了するとCATV経由のBSはBS、CSはCS、CATVの専門チャンネルは `SKY` としてMirakurunへ登録し、自動起動が有効なら配信を再開します。どの種別も2つのチューナー（`TCL-G06-0` / `TCL-G06-1`）どちらにも割り当てます。有料放送の局も一覧には出ますが、契約とB-CASの条件で映像が出ない場合があります。

地デジ・衛星の局設定も保持します。同じ多重がCATVと衛星の両方にある場合はCATVを優先します。両チューナーとも `[GR, BS, CS, SKY]` で、 `ONID_TSID_SID` の選局指定をそのまま使い、配信本体が周波数とTSMF設定を選びます。

共有するネイティブ実装はTCLTV-BondriverのCATV対応版です。スキャン結果はTV内の `/data/local/tmp/tsd_catv_channels` に保存され、BonDriver側とも共用できます。スキャン失敗時には前のCATV局一覧を保持します。

J:COMでは、CATVの専門チャンネルに加えて、CATV経由のBS（BS11・BS朝日・BS-TBS・BS日テレ・BSフジなど）も `SKY` として登録されます。Mirakurunが各多重の局情報を取得し終えるまで、起動後しばらくかかります（取得に失敗した多重は180秒ごとに自動で再試行されます）。
実機ではJ:COMのBS11を地デジ端子経由で受信し、通常のB-CAS処理を使う1920×1080映像と48kHz音声を確認しました。受信可能な番組は信号・契約・カードの条件によります。

## TV画面に「非契約・視聴鍵無し（A103）」を出さない

CATVの有料局を受信すると、TV本体のB-CAS処理がECMエラー（A103）を検出し、TVアプリが通知を表示してHDMI入力から切り替えることがありました。配信本体は、CATV受信中だけエラーコードの取得（libisdb.so の 	vhdtv_bcas_get_ecm_retcode）を0に置き換えます（PLT/GOTの差し替えのみで、コードは書き換えません）。無効にするには /data/local/tmp/tsd_quiet_off を作成してTVを再起動してください。診断は /data/local/tmp/tsd_quiet.log に出力されます。

## 信号レベル

TSMFのストリームを選択している間は復調器のロックが立たず、TSロックだけが立ちます。信号レベル（C/N）は「どちらかのロック」で取得します。

## 局一覧の種別（Mirakurun）

CATV経由のBSはBS、CSはCS、CATVの専門チャンネルはSKYとして登録し、種別ごとにまとめて並べます（TVTestのチューナー空間が分割されないようにするため）。

## チャンネルの素早い切り替え

TVTestのチャンネルスキャンなどで、前の選局が終わる前に次の選局が来た場合は、進行中の選局を中断して新しい選局を優先します（応答は `ERR superseded`）。以前は3秒で `ERR busy` になり、BonDriverが「チャンネル変更を受け付けられません」と表示していました。
